# MedArc V2 design system

This is a proposed brand palette, not an official supplied identity guide. All tokens are centralized in `src/app/globals.css`.

- Navy: `#102744` — heading, frame, hero
- Navy deep: `#0B2038` — elevated contrast
- Cobalt: `#145FC7` — primary actions and navigation
- Cobalt dark: `#0C4DA9` — hover
- Teal: `#087965` — confirmation/status
- Ice: `#EDF5FD` — highlight surfaces
- Mist: `#F5F7FA` — application canvas
- White: `#FFFFFF` — content paper
- Line: `#E1E7EE` — discreet dividers
- Muted: `#62758A` — supporting text
- Amber: `#DA9F53` — caution accents

Type: Manrope 600/700/800 for headings, DM Sans 400/500/700 for UI. Google Fonts are loaded at runtime, with system fallbacks. No font files are redistributed.

Design constraints: no cartoon illustrations; strong left edge alignment; rounded corners 8–14px (not exaggerated pills except indicators); 44px+ mobile interactive targets; high contrast for body text and buttons; mobile bottom navigation; consistent 8px spacing system.

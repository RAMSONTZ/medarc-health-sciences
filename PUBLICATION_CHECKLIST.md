# MedArc publication acceptance checklist

- [x] MedArc-only header, navigation, anatomy syllabus and empty-state language.
- [x] Restricted third-party image files, raw HTML sources, copyright-marked slides and private image bundles excluded from public assets.
- [x] All original question IDs, examinations and provisional answers preserved.
- [ ] Confirm redistribution rights of imported question bank and medical explanations.
- [ ] Verify clinical answer accuracy before representing prepared answers as medically validated.
- [ ] Install dependencies and pass `npm run build` on a connected host.
- [ ] Run Chromium desktop/mobile integration tests against deployed preview.
- [ ] Review any externally hosted photography license/model release.
- [ ] Create a new GitHub repository and push this project; GitHub connector currently cannot create repositories in chat.
- [ ] Connect the repository to a Vercel account/team; current Vercel connector returns no team.
- [ ] Confirm public domain/URL and monitor production logs.
